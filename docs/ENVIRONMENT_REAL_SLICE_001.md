# Environment real slice 001

This lane is the first bounded environment replacement-by-contract proof that crosses from proxy-only composition into source-owned department assets without moving source authority into `axm-map-design`.

It stacks on Procedural Design PR #3 and consumes exact retained seed `29`. The map surface, building proxy, three untouched nature proxies and two object proxies remain unchanged. Only `proxy:nature-tree-west-a` is replaced, using the exact source-owned sapling from `axm-nature-design` PR #1 at head `fbc202449981f2bac153951c561ed0ed6120c936`.

The replacement does not scale or reshape the Nature asset. Environment preserves the procedural variant's placement centre, grounds the source mesh by its own minimum Z, and verifies the real mesh footprint/height remain inside the reserved proxy envelope before re-checking path clearance and minimum spacing.

The same scene also overlays the exact source-owned visual streak field from `axm-weather-design` PR #2 at head `ca2eaba519e8449835b0ea6ef944b7080c3caa6a`, sampled at its authored `0.50 s` frame. Weather remains `VISUAL_DIRECTION_ONLY_NOT_PHYSICAL_WIND_SPEED`; no wind force, vegetation bend or physics claim is introduced.

## Retained evidence

The workflow checks out the two exact public dependency heads, re-runs their source evaluators in the receiving map CI, then generates:

- `before_seed29_proxy.svg` — the exact structurally accepted procedural proxy composition;
- `after_source_slice.svg` — the same composition with one real sapling mesh and the source-owned weather overlay;
- `comparison.svg` — direct before/after world-art comparison;
- `scene.obj` — proxy scene geometry plus the exact transformed 390-vertex / 570-triangle sapling mesh;
- `evidence.json` — exact provenance, digests, composition gates and non-claims.

The dependency PASS states are not inherited. The receiving lane independently verifies the pinned procedural study digest, Nature source and mesh digests, Weather source digest, source evaluators, reserved envelope, path clearance, spacing, scene extent, direction semantics and authored weather sample.

## Truth boundary

A PASS means only that this exact source-owned sapling can replace this exact nature proxy in this exact structurally valid seed-29 composition without breaking the bounded map spacing/path envelope, while this exact source-owned visual weather field can be overlaid with matching scene extent and direction semantics.

It does **not** prove final environment composition, botanical correctness, branch topology, vegetation deformation, physical weather, materials, lighting, gameplay/traversal, collision, engine import, runtime cost, Art Director acceptance, CANON, production readiness or environment/world-art mastery.

## Handoff

Art Director / Visual Observer should compare the retained before/after images for hierarchy, negative space, vegetation scale and whether the weather overlay helps or obscures the central corridor. VFX may later test visible sapling response, but only after this static placement is accepted. Runtime should measure only after a real renderer/engine consumes the combined scene.
