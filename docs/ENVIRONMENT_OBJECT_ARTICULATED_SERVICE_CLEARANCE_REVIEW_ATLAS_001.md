The previous Environment proof is strong but large: `272` rendered PNGs. The candidate itself is intentionally subtle because only one Map-owned dressing edge moves `20 mm`. A compact deterministic atlas makes the handoff inspectable while preserving the exact source frames and avoiding camera-shopping or selective screenshot claims.

## Fail-closed boundary

The generator refuses to run if:

- the retained source archive SHA-256 changes;
- the exact source head changes;
- the inherited render report schema/result changes;
- Environment adoption is unexpectedly true;
- the owner-sample set changes;
- predecessor/successor frame dimensions diverge.

The dedicated workflow also runs a negative control with an intentionally stale exact-head contract; success requires that stale pin to be rejected.
