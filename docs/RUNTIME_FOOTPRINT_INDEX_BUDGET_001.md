# Runtime — Footprint cue index budget 001

## Bounded question

Can the exact Art-preferred Map-owned west Object footprint cue keep its one surface, 48 triangles, material, placement and rendered appearance while replacing repeated unindexed triangle-corner vertices with a post-normal indexed representation?

## Exact parent

This Runtime lane starts from Environment head:

`b9d9ed28e9a826c4698014db5f91c59aba9dddfc`

That parent already includes:

- the Art-preferred visible cue `environment:dressing:west-object-service-footprint-frame-001`;
- the Environment-adopted indexed five-surface Object receiver from Runtime PR #33;
- the exact current Building, Nature, Weather, route, cameras and lighting chain.

No source asset or visual role is changed here.

## Representation A/B

Control:

- run the existing cue exactly as emitted;
- keep the cue visible;
- record its live ArrayMesh surface/vertex/index/triangle counts and renderer counters.

Candidate:

- after the cue has already been generated and normals already exist, import the exact one surface into `SurfaceTool`;
- call `SurfaceTool.index()`;
- commit the indexed mesh back to the same `MeshInstance3D`;
- preserve the node material override, transform, visibility and all parent-world state.

The candidate is accepted only if it reduces the stored vertex/logical payload representation while preserving the one-surface / 48-triangle boundary, matching all 68 retained current-world PNGs byte-for-byte, and not increasing observed proof-host buffer memory or changing draw/object/primitive/texture counters.

## Why this lane is useful

Runtime PR #33 already proved post-normal indexing on a materially different imported five-surface Object receiver. The footprint cue is generated by Map itself as a single-surface four-box readability frame. A successful result would therefore be independent second-domain evidence that the mechanism may deserve capability-placement review, while still being too narrow for automatic Universal Creation extraction.

## Visual tradeoff gate

Art Direction has already preferred the exact cue in its current restrained form. Runtime therefore treats any retained-pixel change as a failure. A PASS says only that the representation changed without an observed visual delta in the fixed proof scope; it does not re-approve the cue aesthetically.

## Truth boundary

This experiment does not claim target-device FPS, CPU/GPU frame time, VRAM/heap reduction, arbitrary procedural-mesh safety, import-time generalization, gameplay/collision/navigation acceptance, final Art Direction, CANON, production readiness, UC promotion or Runtime mastery.
