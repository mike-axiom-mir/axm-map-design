## Strict visual gate history

The first real-host run `35154600246` preserved a strict byte-identical visual gate and **failed it**. Both Godot control and candidate observations themselves completed successfully; verification failed because all 68 matched PNGs were non-identical.

Inspection of the retained failed artifact narrowed that difference exactly:

- one changed pixel per retained frame;
- one RGB channel changed;
- maximum magnitude one LSB;
- the delta stayed inside the projected footprint-cue bounds;
- the differing coordinate was stable per camera.

The strict failure remains historical evidence. It is not rewritten into byte-identical success.

The repaired verifier therefore measures this nonzero consequence directly and may pass only if every retained frame remains bounded to at most one changed pixel, at most one RGB LSB, inside the projected cue bounds. Any larger or escaped visual delta fails closed. Final acceptance of that tradeoff remains Art Direction / Visual QA authority.

A successful bounded result therefore becomes independent second-domain evidence that the mechanism may deserve capability-placement review, while still being too narrow for automatic Universal Creation extraction.
