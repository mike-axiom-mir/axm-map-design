- all non-frame static-source rows remain byte-equivalent as JSON data;
- Object source/material/UV/roughness/motion identity remains exact;
- Building and Nature state rows remain exact;

- camera contexts and presentation modes remain exact;
- proof-host runtime counters remain exact;
- every raster delta, if any, stays inside the union of predecessor/successor projected dressing bounds plus a two-pixel antialiasing guard;
- zero raster delta is characterized honestly rather than converted into a source amplification or camera move.

No minimum changed-pixel threshold is invented. A localized visible delta and a zero-raster result are both valid evidence outcomes; neither grants adoption.
